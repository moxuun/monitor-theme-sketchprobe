# 全球节点地图原型

探针主题里那张「运维工程师画在纸上的全球节点图」的独立原型。**不接入现有页面，也不参与主题构建**——它只用来把地图的视觉和交互定下来，确认之后再往主题里搬。

## 跑起来

```
npx vite -c map-preview/vite.config.ts
```

打开 http://localhost:5199 。这个 config 只指向本目录，仓库根目录的 `npm run dev` 照旧服务主题，互不影响。

## 怎么操作

| 操作 | 效果 |
| --- | --- |
| 滚轮 | 缩放 1–4 倍，以指针位置为锚点 |
| 拖动 | 平移；上下到头会停住，左右无限循环 |
| `+` `−` `⤢` | 放大 / 缩小 / 回到全图 |
| 方向键、`+` `-` `0` | 地图获得焦点后的键盘等价操作 |
| 点标记 | 选中，下方列出该地的节点；再点同一个则取消 |
| 点地图别处、`Esc` | 取消选中 |
| 悬停 / Tab | 只看名字，不动下面的列表 |

工具提示跟着悬停和焦点走，下面的节点列表只跟着「点选」走——所以鼠标从标记移到列表上时列表不会消失。

## 文件

| 文件 | 作用 |
| --- | --- |
| `world.ts` | 生成的国界 path 数据。**不要手改**，改生成脚本 |
| `build-world.mjs` | 从 Natural Earth 生成 `world.ts` |
| `PencilDefs.tsx` | 彩铅排线，真正的 SVG `<pattern>` |
| `pen.ts` | Rough.js 的封装：外框、罗盘、节点圈线，固定种子 |
| `WorldMap.tsx` | 地图本体、缩放平移、标记与选中 |
| `fixtures.ts` | 样例节点（含停机、无数据、未知位置） |
| `main.tsx` | 原型外壳：标题、图例、场景切换 |
| `styles.css` | 纸张、配色、深浅两套 |
| `shot-*.png` | 验证截图（全图 / 4 倍 / 接缝 / 深色 / 窄屏） |

## 重新生成地理数据

只有地理本身要改时才跑：

```
node map-preview/build-world.mjs
```

会下载 Natural Earth 的 110m 和 50m 国界到 `.cache/`（已 gitignore），之后重跑不再联网。缓存不随主题发布，发布的是生成出来的 `world.ts`。

## 几个刻意的选择

**手绘只画结构和装饰。** 国界是精确 path，一个点都不抖；外框、罗盘、节点圈线才交给 Rough.js，并且用固定种子，每次画得一样——装饰可以歪，数据不能。

**停机用灰，红色留给 CPU 打满。** `!online` 走灰色的 `off`，红色只表示“在线但 CPU ≥ 90%”——两件事不共用一个颜色。“在线但无数据”用同一个灰、但点画成空心的，靠实心/空心分开。聚类取最重的一个，权重是 `bad > warn > off > ok > idle`。

**彩铅纹理是屏幕尺度的。** `patternTransform` 里带了 `scale(1/s)`，所以放大时排线不会跟着变粗。这是有意的：放大应该让你看到更多地图，而不是看到更粗的铅笔。代价是放大不会变出新海岸线，所以上限设在 4 倍——再放大看到的是 110m 数据的坐标阶梯。

**排线是连续的。** 最早让每笔都不画满一格，想让瓷砖接缝看不出来，结果在这个间距下变成规整的点阵，更像网点纸而不是排线。现在每笔都画到格边，相邻格自然接成一条线，变化靠笔重和深浅。

**经度是圆的，所以左右不封边。** 地图东西向重复，窗口跨过接缝时同一张图会画第二遍。海面的底色因此放在元素背景上而不是图案里——底色留在图案里的话，接缝处两块叠起来会显出一条带。纬度不是圆的，上下仍然到头就停。

**平移按帧合并。** 鼠标每秒能报上千次位置，每次触发一次 React 渲染是白烧。位移先累积、每帧提交一次，而且用 `flushSync` 同步提交：React 对事件回调之外的状态更新走的是宏任务，不强制同步的话这一帧的位移要等到下一帧才画出来。同样因为不逐事件渲染，地理图元被 `memo` 包住——平移只改一个 transform，不再逐帧重新 diff 几百条 path。

## 已知限制

- **相邻标记会重叠。** 1 倍时荷兰和德国两个标记只隔 13 px，而点击区是 30 px，点到的可能是旁边那个。放大能分开（4 倍时相距 54 px，各自点得中），但原型没做聚类或自动散开。
- **没有双指缩放。** 单指拖动可以，触摸板双指滚轮也可以。
- **标记落点是国家/地区示意位置**，不是机房位置——数据里只有国家代码，没有经纬度。
