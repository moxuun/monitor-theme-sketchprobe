# SketchProbe 主题 · 设计审查

**审查基线** `413c173`（`main` `0ca7905` + 在飞分支 `feat/detail-fact-icons`、`feat/detail-panels-stack`、`feat/card-latency`）
**审查环境** Chrome via CDP。模拟视口 1140×1000 → **实际 CSS 视口 900×800**（DPR 1.25）；手机档模拟 390×844 → **实际 300×675**。下面每个数字都是 `getBoundingClientRect` 实测，不是目测。模拟数据每次重绘会变，前后截图里数值不同属正常。
**证据** `fleet-light.png`（列表页）、`detail-light.png`（详情页）、`offline-before-after.png`（这一版的前后对比）。

## 结论

**手绘图标没有在重量上压过监控数据。** 参数区 12 枚 13px 图标 + 面板标题 4 枚 14px 图标，全页 18 枚。实测一枚图标与它旁边的两个汉字墨量几乎相等（图标 mean 198 / 墨占 23.6%，文字 mean 199 / 墨占 24.4%），8 倍放大下两者的光学中心也齐。所以「图标抢注意力」在单枚的轻重上不成立，它们是合格的注脚。

真正在**面积**上压过数据的有两处：离线卡片的深色斜纹地面（已改），和三张图 `opacity .13` 的面积填充（建议，未改）。三张图的填充分别占各自绘图区的 52.2% / 48.0% / 77.0%，折线本身很轻，填充比它概括的数据重。

层级的问题不在图标而在字体：详情页 8 处读数全部比自己的标签小——`.panel-now` 对 `.panel-title`、`.meter-value` 11.5px 对 `.meter-name` 13px；列表页却相反，`.tile-value` 是 25px。同一个主题里两套相反的层级。

## 已确认的问题（实测）

1. **没有回到顶部 / 跳到底部**（用户指出，实测属实）。审查时全站 `position: fixed|sticky` 元素数为 0；详情页 2.29 屏、列表页 2.72 屏（900×800），手机档 3.44 / 4.67 屏；只有换页时 `navigate()` 调 `scrollTo(0,0)`。滚动之后顶部导航和分组筛选全部滚走，要回顶部只能拖滚动条。**已在这一版实现。**
2. **离线卡片的斜纹地面是整页最抢眼的东西。** `src/components/NodeCard.tsx:20`（基线）对离线节点用 `--muted` 铺满整张卡，面积最大、最重；而离线卡恰好是数字最少的一张，被强调的是一片空白。**已改**，见 `offline-before-after.png`。
3. **读数在尺寸与墨色两项上都排在标签之后。** 见上。这一版只把 `.meter-value`、`.panel-now` 的墨色提到 `--ink`，尺寸基本未动（原因见下表第 3 条）。
4. **地图把首屏占满。** 地图 856×333，占列表页 15.3%；第一个节点卡从 y=809 开始，也就是刚好掉在 800px 折线下面——首屏看得到地图和汇总，看不到任何节点。**取舍，未改。**
5. **浮动跳转按钮压住内容列右缘 14px。** 按钮 32px 宽、外壳右留白 22px，`right: max(4px, …)` 放不下。实测它落在 x=864，而面板内文字区右缘在 863——正好让开 1px，所以 300 与 900 两种视口下按钮矩形与任何文字元素都**没有交集**，压住的是面板自己的右边距。滚动时仍可能擦过右对齐读数的尾部；要完全消除得把按钮缩到 ≤22px 宽，或给外壳加右留白。

## 主观建议（未改，只列出来讨论）

- **字号与间距的密度。** CSS 里 17 个字号（8.5–27px），详情页实际渲染 10 个、列表页 12 个，其中 11 / 11.5 / 12 / 12.5 / 13 / 13.5 六个挤在 2.5px 内；`body` 声明 14px 却只有两条规则用它。间距同理：12 个 `gap` 值、约 15 个 `padding` 值，多数只差 1–3px。不同字体本来就需要光学校准，所以这不是缺陷，但值得收一次。
- **图标数量。** 单枚不抢眼，18 枚同重量的几何符号放在一起，比它们标注的文字更密。要减的话减数量，不是减大小。
- **窄屏。** 300 CSS px 下 `.meter-row` 的 `34px + 1fr + 122px` 只剩约 100px 给进度条；事实区三列时最后一个值被截 2px（`.fact-value hand`「AMD EPYC 7763 · 4 核」需要 153px、只有 151px）。

## 保留（做得对的）

- **对齐是干净的。** 外层内容边全部在 x=22（`.tabs`、`.detail-head`、`.facts`、`.panel`），内层全部在 x=37（`.panel-title`、`.meter-row`、`.chart`）。没有错位。
- **卡片内三列在所有卡之间严格对齐。** `.meter-row` 的 `34px + 1fr + 122px` 固定数值列就是为此：跨卡比条形时终点一致，`122px` 也是按最长值「1023 MB / 2.00 GB」定的。
- **轴标签与字段名的对比度在前几轮已经提上来了**，这一版没有回退它们。

## 这一版改了什么

| 文件 | 改动 |
| --- | --- |
| `src/App.tsx`、`src/index.css`（`.jump`） | 新增「回到顶部 / 跳到底部」两个原生按钮：沿用现有箭头图标、`aria-label` + `title`、`:focus-visible` 虚线焦点环；目标在按下时才读 `document.documentElement.scrollHeight`，不依赖初次加载高度；即时滚动，没有平滑滚动、没有观察器、没有新导航框架。 |
| `src/components/NodeCard.tsx` | 离线节点不再用 `--muted` 铺满，改用与其他卡相同的 `--hatch`；状态语义（徽章、文案、状态图标）未动。 |
| `src/index.css` `.meter-value` | `--ink-soft` → `--ink`。字号保持 11.5px：`122px` 数值列在最长值下已用掉 115px，再上一档 12px 只剩 1.6px 余量，会截断。 |
| `src/index.css` `.panel-now` | 13px / `--ink-soft` → 14px / `--ink`：比标题小一档，但用标题的墨色。 |

**没改**：单列面板布局、220px 图表高度、图表面积填充、地图高度、事实区结构、图标数量、字号与间距体系、全站对齐基线。
