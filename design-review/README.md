# SketchProbe 主题 · 设计审查

**审查基线** `413c173`（`main` `0ca7905` + 在飞分支 `feat/detail-fact-icons`、`feat/detail-panels-stack`、`feat/card-latency`）
**审查环境** Chrome via CDP，浅色主题。模拟视口 1140×1000 → **实际 CSS 视口 900×800**（DPR 1.25）；窄屏模拟 443×900 → **实际 342×800**，模拟 390×844 → **实际 300×675**。下面每个数字都是 `getBoundingClientRect` / `scrollWidth` 实测，不是目测。列表页 9 张节点卡。模拟数据每次重绘会变，截图之间数值不同属正常。
**证据** `fleet-light.png`（列表页）、`detail-light.png`（详情页）、`offline-before-after.png`（离线卡前后，同一视口与主题）。

## 结论

**手绘图标没有在重量上压过监控数据。** 参数区 12 枚 13px 图标 + 面板标题 4 枚 14px 图标，全页 18 枚。实测一枚图标与它旁边的两个汉字墨量几乎相等（图标 mean 198 / 墨占 23.6%，文字 mean 199 / 墨占 24.4%），8 倍放大下两者的光学中心也齐。所以「图标抢注意力」在单枚的轻重上不成立，它们是合格的注脚。图标数量能不能证明抢注意力，这次的截图证明不了；能说的是**没有观察到小型行内图标压过读数**。

按面积算，页面上压过数据的是两处：离线卡片的深色斜纹地面（这一版已改），和三张图 `opacity .13` 的面积填充。填充分别占各自绘图区的 52.2% / 48.0% / 77.0%。**但面积不能和折线的实线像素直接比较**——填充是 13% 透明，对纸色只有 1.17:1 的对比（暗色 1.26:1），所以它不响在对比度。面积填充是否增加视觉负担是主观判断，这一版没有据此动它。

层级的问题不在图标而在字体：详情页的读数比自己的标签小（`.panel-now` 14px 对 `.panel-title` 15px、`.meter-value` 11.5px 对 `.meter-name` 13px），列表页却相反（`.tile-value` 25px）。同一主题里两套相反的层级。**详情页的读数是历史图旁边的辅助摘要，比标题小不必然是层级倒置**，这一版只做了可读性调整，没有把它写成已证实的缺陷。

## 已确认的问题（实测）

1. **没有回到顶部 / 跳到底部**（用户指出，实测属实）。审查时全站 `position: fixed|sticky` 元素数为 0；详情页 2.29 屏、列表页 2.72 屏（900×800），窄屏 3.44 / 4.67 屏；只有换页时 `navigate()` 调 `scrollTo(0,0)`。滚动之后顶部导航和分组筛选全部滚走。**已在这一版实现。**
2. **离线卡片的斜纹地面是整页最抢眼的东西。** 基线 `src/components/NodeCard.tsx:20` 对离线节点用 `--muted` 铺满整张卡，面积最大、最重；而离线卡恰好是数字最少的一张，被强调的是一片空白。**已改**，见 `offline-before-after.png`。
3. **列表页卡片网格在窄屏横向溢出 44px，溢出后读数会滑到浮动按钮底下。** `src/index.css:566` 的 `minmax(310px, 1fr)` 是固定下限，外壳窄于 310px 时这一列就撑出去：实测 CSS 视口 288px 下 `scrollWidth - clientWidth = 44`，卡片右缘到 x=332，而外壳右缘在 266。**已改**（`min(100%, 310px)`），见下表。
4. **浮动按钮压住内容列右缘。** 按钮原本 32px 宽，落在 x=864，而面板文字区右缘在 863——只让开 1px；窄屏更糟，实测按钮左缘 258、最右读数右缘 316，被压住 58px。**已改**：按钮收到 26px（仍在 24px 最小点击区之上），左缘固定在外壳右缘再往内 8px。三档视口实测最右读数与按钮左缘的间距都是 7–8px，全滚动范围内按钮矩形与任何文字元素**无交集**（只与 `.summary`、`.map`、`.tabs` 三个整宽容器盒相交 8px，其内容左对齐，够不到）。
5. **地图把首屏占满。** 地图 856×333，占列表页 15.3%；第一个节点卡从 y=809 开始，也就是刚好掉在 800px 折线下面——首屏看得到地图和汇总，看不到任何节点。**取舍，未改。**

## 主观建议（未改，只列出来讨论）

- **字号与间距的密度。** CSS 里 17 个字号（8.5–27px），详情页实际渲染 10 个、列表页 12 个，其中 11 / 11.5 / 12 / 12.5 / 13 / 13.5 六个挤在 2.5px 内；`body` 声明 14px 却只有两条规则用它。间距同理：12 个 `gap` 值、约 15 个 `padding` 值，多数只差 1–3px。不同字体本来就需要光学校准，所以这不是缺陷，但值得收一次。
- **图标数量。** 单枚不抢眼，18 枚同重量的几何符号放在一起，比它们标注的文字更密。要减的话减数量，不是减大小。
- **窄屏的取舍。** 300 CSS px 下 `.meter-row` 的 `34px + 1fr + 122px` 只剩约 100px 给进度条；事实区三列时最后一个值被截 2px（`.fact-value hand`「AMD EPYC 7763 · 4 核」需要 153px、只有 151px）。这两处都是固定列宽换来的跨卡对齐，没有改。

## 保留（做得对的）

- **对齐是干净的。** 外层内容边全部在 x=22（`.tabs`、`.detail-head`、`.facts`、`.panel`），内层全部在 x=37（`.panel-title`、`.meter-row`、`.chart`）。
- **卡片内三列在所有卡之间严格对齐。** `.meter-row` 的 `34px + 1fr + 122px` 固定数值列就是为此：跨卡比条形时终点一致，`122px` 也是按最长值「1023 MB / 2.00 GB」定的。
- **轴标签与字段名的对比度在前几轮已经提上来了**，这一版没有回退它们。

## 这一版改了什么

| 文件 | 改动 |
| --- | --- |
| `src/App.tsx`、`src/index.css`（`.jump`） | 新增「回到顶部 / 跳到底部」两个原生按钮：沿用现有箭头图标、`aria-label` + `title`、`:focus-visible` 虚线焦点环；目标在按下时才读 `document.documentElement.scrollHeight`，不依赖初次加载高度；即时滚动，没有平滑滚动、没有观察器、没有新导航框架。按钮 32px → 26px 并改为固定在外壳右缘内 8px。 |
| `src/components/NodeCard.tsx` | 离线节点不再用 `--muted` 铺满，改用与其他卡相同的 `--hatch`；状态语义（徽章、文案、状态图标）未动。 |
| `src/index.css` `.grid` | `minmax(310px, 1fr)` → `minmax(min(100%, 310px), 1fr)`：外壳窄于 310px 时不再横向溢出。310px 以上行为完全不变（900 视口下页高 2152 前后一致）。 |
| `src/index.css` `.meter-value` | `--ink-soft` → `--ink`。字号保持 11.5px：`122px` 数值列在最长值下已用掉 115px，再上一档 12px 只剩 1.6px 余量，会截断。 |
| `src/index.css` `.panel-now` | 13px / `--ink-soft` → 14px / `--ink`：比标题小一档，但用标题的墨色。 |

**没改**：单列面板布局、220px 图表高度、图表面积填充、地图高度、事实区结构、图标数量、字号与间距体系、全站对齐基线。

## 验证

- `npm run typecheck`（`tsc -b --noEmit`）退出码 0；`git diff --check` 退出码 0。
- **键盘**（真实 CDP 按键，非脚本 `.click()`）：焦点在「回到顶部」时按 Enter，`scrollY` 1172 → 0；焦点在「跳到底部」时按 Space，781 → 1669（= 最大滚动位置）。
- **横向溢出**：CSS 视口 288 / 342 / 900 三档下 `scrollWidth - clientWidth` 全为 0（改前 288 档为 44）。
- **遮挡**：三档视口 × 全页滚动范围（每 55px 一采样）扫描 `.meter-value`、`.card-name`、`.card-foot`、`.badge`、`.tile-value`、`.fact-value`、`.panel-now`、`.tabs` 等元素与按钮矩形的交集，最大交集 8px 且只出现在整宽容器盒上，**没有任何文字元素被按钮覆盖**；最右读数与按钮左缘间距 7–8px。
- **截断**：`.meter-value` / `.panel-now` / `.tile-value` / `.badge` / `.card-foot` 在 288、342、900 三档下 `scrollWidth` 均未超过 `clientWidth`。
